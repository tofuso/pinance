# pinance

収支管理のためのPython製ツール

## 機能

このツールは以下のことを行えるようにする。

| 大分類 | 機能 | 詳細 |
|:--:|:--:|:--|
| 読み込み | 口座収支CSV読み込み | 銀行サービスなどが発行する取引収支および残高を記録したCSVファイルを読み込めること。データの重複は除外すること。（三井住友銀行など）|
| 読み込み | クレジットカード取引読み込み | クレジットカードなどが発行する取引CSVデータを読み込めること。データの重複は除外すること。次のクレジットカード取引を読み込む。銀行の口座収支にクレジットカードの支出が含まれるため、全体の収支寒山には使用しない。（Vpass）|
| 保存 | 口座情報の保持 | 読み込んだ取引データを永続化する。 |
| 閲覧 | 収支の一覧化 | これまで入力した取引と残高を時系列順に閲覧できること。|
| 閲覧 | 収支の期間ごとの閲覧 | これまで入力した取引と残高を日、週、月、年毎にページして閲覧できるようにすること。 |
| 閲覧 | 収支の期間ごとの統計 | これまで入力した取引と残高を日、週、月、年毎に収支について、グラフで閲覧できること。|
| 閲覧 | クレジットカード情報の表示 | 読み込んだクレジットカードの明細データを、口座のクレジットカード引き落としデータから展開する形式で内訳を確認できるようにする。 |

## セットアップ・起動

```bash
source .venv/Scripts/activate
pip install -e ".[dev]"
uvicorn pinance.main:app --reload
# → http://localhost:8000 をブラウザで開く
```

## テスト実行

```bash
pytest -v
```
